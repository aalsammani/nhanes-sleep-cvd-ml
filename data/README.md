# Data instructions

The dataset is intentionally excluded from this GitHub repository.

## Expected dataset

Place the cleaned analysis dataset used by the notebook in the appropriate working directory. The recommended filename is:

```text
nhanes_sleep_cvd_clean_analysis_2013_2023.csv
```

If your file uses a different name, update the dataset filename in the notebook's data-loading cell.

## Public source

The source data come from the National Health and Nutrition Examination Survey (NHANES), administered by the U.S. Centers for Disease Control and Prevention.

## Recommended practice

- Do not upload large raw or processed data files to GitHub.
- Do not include any restricted or personally identifiable information.
- Document all inclusion criteria, variable mappings, and transformations.
- Verify that every reported sample size and figure is regenerated from the same analytic dataset.
